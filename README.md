# ECommerceProject

Проект по ООП для создания интернет-магазина.

## Реализованы классы

- класс `Product` для описания товара;
- класс `Category` для описания категории товаров;
- автоматический подсчет количества категорий, товаров;
- чтение данных из JSON-файла;
- создание объектов `Product` и `Category` из JSON.

## Product

Класс товара содержит:

- `name` — название товара;
- `description` — описание товара;
- `price` — цена;
- `quantity` — количество в наличии.

## Category

Класс категории содержит:

- `name` — название категории;
- `description` — описание категории;
- `products` — список товаров.

Атрибуты класса:

- `category_count` — количество созданных категорий;
- `product_count` — количество товаров во всех категориях.
