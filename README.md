# ECommerceProject

Проект по ООП для создания интернет-магазина.

## Реализованы классы

- класс `Product` для описания товара;
- класс `Category` для описания категории товаров;
- автоматический подсчет количества категорий, товаров;
- чтение данных из JSON-файла;
- создание объектов `Product` и `Category` из JSON.

## Product

Класс товара содержит:

- `name` — название товара;
- `description` — описание товара;
- `price` — цена;
- `quantity` — количество в наличии.

## Category

Класс категории содержит:

- `name` — название категории;
- `description` — описание категории;
- `products` — список товаров.

Атрибуты класса:

- `category_count` — количество созданных категорий;
- `product_count` — количество товаров во всех категориях.

## Режимы доступа и методы классов

В проект добавлена новая функциональность для классов `Product` и `Category`.

### Изменения в Category

- список товаров сделан приватным атрибутом;
- добавлен метод `add_product()` для добавления товара в категорию;
- добавлен геттер `products`, который возвращает список товаров в строковом формате.

### Изменения в Product

- атрибут цены сделан приватным: `__price`;
- доступ к цене реализован через геттер `price`;
- изменение цены реализовано через сеттер `price`;
- сеттер запрещает устанавливать нулевую или отрицательную цену;
- при попытке установить цену `0` или ниже выводится сообщение:
  `"Цена не должна быть нулевая или отрицательная"`;
- добавлен класс-метод `new_product()` для создания товара из словаря.

## Наследование и ограничения типов

В проект добавлены классы-наследники класса `Product`:

- `Smartphone` — класс для смартфонов;
- `LawnGrass` — класс для газонной травы.

Класс `Smartphone` содержит дополнительные атрибуты:

- `efficiency`;
- `model`;
- `memory`;
- `color`.

Класс `LawnGrass` содержит дополнительные атрибуты:

- `country`;
- `germination_period`;
- `color`.
